# AGRobase

AGRobase — типологическая база данных по согласованию в языках мира. Она помогает исследователям сравнивать языки по лингвистическим признакам, подбирать выборки и находить примеры с библиографическими источниками.

Например, можно посмотреть, согласуется ли сказуемое с субъектом или прямым объектом, на каких формах глагола выражается согласование и как эти свойства сочетаются с другими характеристиками языка.

Проект разрабатывается в рамках исследовательской практики в лаборатории по формальным моделям в лингвистике НИУ ВШЭ. Сейчас это небольшой, пополняемый набор данных, а не исчерпывающий справочник по всем языкам мира.

## Что есть на сайте

- **Features** — общая таблица языков и признаков с фильтрами, переключением на карту и просмотром примеров.
- **Languages** — список языков с поиском, генетической принадлежностью и ссылками на источники. На странице языка собраны его параметры и примеры.
- **Parameters** — описание каждого признака, его значения по языкам и карта.
- **Sources** — библиография, на которую опираются данные.

Есть и отдельная страница `/feature-combinations`: на ней можно выбрать до трёх значений признаков и получить языки, у которых встречаются все выбранные значения.

## Как устроен проект

Сайт написан на Python с использованием **CLLD** — фреймворка для лингвистических веб-баз. CLLD предоставляет стандартные сущности языков, параметров, значений, примеров и источников. AGRobase использует эту модель и дополняет её связью между примерами и параметрами: один пример может иллюстрировать несколько признаков.

Бэкенд работает на **Pyramid**, а к базе обращается через **SQLAlchemy ORM**. Для локального запуска используется **SQLite**: база хранится в файле рядом с конфигурацией приложения. HTML-страницы собираются шаблонами **Mako**, интерактивные таблицы используют **jQuery/DataTables**, карты — **Leaflet**.

Исходные материалы хранятся в CSV и BibTeX. Так участники проекта могут дополнять их в привычном табличном формате. При инициализации Python-скрипт читает файлы, преобразует записи в связанные сущности и загружает их в реляционную базу. Во время работы сайт читает данные уже из неё.

В базе язык и параметр связаны через `ValueSet`, а конкретные значения хранятся в `Value`. Примеры и библиографические ссылки вынесены в отдельные таблицы. Большая таблица на сайте собирается из этих данных и не является отдельной таблицей БД.

Поиск и пагинация в таблице языков выполняются на сервере. В общей таблице Features часть фильтров работает в браузере по уже загруженным строкам; примеры подгружаются отдельным запросом.

## Данные

Исходные файлы находятся в [`agrobase/agrobase/data/`](agrobase/agrobase/data/):

| Файл | Что в нём хранится |
| --- | --- |
| `languages.csv` | Языки, координаты, генетическая принадлежность и Glottocode |
| `parameters.csv` | Параметры, их описания, группы и иерархия |
| `codes.csv` | Допустимые значения параметров |
| `values.csv` | Значения параметров для языков, комментарии и ссылки на источники |
| `examples.csv` | Тексты примеров, глоссы, переводы и связанные параметры |
| `sources.bib` | Библиографические записи |

Изменения в CSV не появляются на сайте автоматически: после редактирования нужно повторить загрузку. Как добавлять данные, описано в [инструкции для участников](agrobase/CONTRIBUTING.md).

## Локальный запуск

Нужны Python 3, Git и виртуальное окружение. Команды ниже предназначены для macOS и Linux.

```bash
git clone https://github.com/poplavushka/agrobase.git
cd agrobase/agrobase
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
cp development.ini.example development.ini
clld initdb development.ini
pserve development.ini --reload
```

Откройте [http://127.0.0.1:6543](http://127.0.0.1:6543). Для карт требуется интернет: подложка загружается с серверов Esri.

Команда `clld initdb` пересоздаёт базу из исходных файлов. Перед повторным запуском сохраните копию существующего `agrobase.sqlite`, если в нём есть нужные изменения. Для обычного запуска уже заполненного сайта достаточно `pserve development.ini --reload`.

Локальный `development.ini`, файл SQLite и виртуальное окружение не включаются в Git. В репозитории хранится только пример конфигурации.

## Где искать код

- [`initializedb.py`](agrobase/agrobase/scripts/initializedb.py) — загрузка CSV и BibTeX.
- [`models.py`](agrobase/agrobase/models.py) — дополнительная связь между примерами и параметрами.
- [`views.py`](agrobase/agrobase/views.py) — страницы, выборки и выдача примеров в JSON.
- [`datatables.py`](agrobase/agrobase/datatables.py) — колонки таблиц, серверный поиск, сортировка и пагинация.
- [`templates/`](agrobase/agrobase/templates/) — страницы, оформление и клиентская логика.
- [`__init__.py`](agrobase/agrobase/__init__.py) — подключение модулей, маршруты и меню.
